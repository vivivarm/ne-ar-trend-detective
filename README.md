# NE-AR · Earth System Trend Detective

**NE-AR (Naturalists Explorer – Augmented Reality).** Explore 45 years of NASA data, test trends with Mann-Kendall and Sen's slope, and see possible futures to 2100.

**Website:** https://vivivarm.github.io/ne-ar-trend-detective/

## Contents
- `index.html` – the website (Trend Detective, e-book, AR app, courses, FAQs)
- `data/` – precomputed NASA data used by the site
- `nasa/` – NASA data helpers
- `docs/` – documentation
- `tests.html` – checks for the statistics

## Data
- [NASA POWER](https://power.larc.nasa.gov/) (MERRA-2), 1981–2025
- [NASA NEX-GDDP-CMIP6](https://www.nccs.nasa.gov/services/data-collections/land-based-products/nex-gddp-cmip6) climate projections to 2100
